## Дизайн-спека по зонам

- **Кузов**: двухрядная кабина (4 двери), длинная платформа. Красный глянцевый (≈ #C81F2E)
  с чёрным нижним поясом/пластиком. Хрома нет — весь трим чёрный/тёмный металл.
- **Передок**: решётка с вертикальными ламелями в чёрной рамке, над ней кузовная плашка
  с надписью KAMAZ и волчьим бейджем по центру. Угловатые узкие LED-фары с ледяной DRL-полосой.
  Капот с двумя воздуховодами и красными акцентами. Силовой бампер с чёрной защитой,
  2 красные буксировочные проушины, противотуманки с LED.
- **Арки/пороги**: расширенные чёрные арки с видимыми болтами, боковые ступени с металлической
  накладкой. Рейлинги на крыше; экспедиционный багорник на крыше с белой LED-балкой (Light_Top!).
- **Платформа**: чёрная рейка-спортс-бар за кабиной, борта с чёрной облицовкой, надпись KAMAZ
  на рейке/борту, чёрный тент/крышка либо открытый пол с рёбрами (решить при моделировании).
- **Зад**: C-образные вертикальные LED-фонари (белый + красный сегменты), чёрный силовой бампер,
  2 красные шаклы, квэд-эхауст (4 серебристые насадки), козырёк над номером.
- **Салон**: чёрная кожа с красной стёжкой/кантом (сиденья SM_KAMAZ_Pickup_Seat_*),
  мультируль с красной верхней меткой, цифровая приборка + широкий центральный дисплей
  (Dashboard — SK-часть), красная подсветка. Ремни/ручки/педали — по мере бюджета.
- **Колёса**: грязевая резина с крупными грунтозацепами, чёрный диск с красным кольцом
  по ободу и красным колпаком ступицы. 4 базовых + бронированные варианты позже.

## Бюджеты (игровые, LOD0)

- Итого по машине: ~150–250k tris. Колесо 10–15k; панель кузова 15–25k; дверь 8–12k;
  бампер 6–10k; фара 2–4k; сиденье 5–8k; приборка 10–15k; рейка/багорник 5–8k.
- UV: тайлы 0–1 на часть, texel ~1024px/м для кузова, 512 для мелочи.
- PBR: свой набор MI_/T_ (красный глянец, чёрный пластик/текстурит, резина, металл,
  стекло с тонировкой, LED-эмиссив). Пока — WorldGridMaterial (Patch 3, ограничение).

## Порядок работ (фазы)

1. **Фаза A — SM-части по доказанному пути**: колёса (муд-терра + красное кольцо),
   Light_Top (LED-балка), фары/фонари, RoofRack, сиденья, Alternator/Battery.
   Каждая часть: Blender → FBX → import под именем клона → cook → staging → один пак.
2. **Фаза B — SK-кузов**: 4 панели + 4 двери + капот + борт + бамперы + приборка
   на скелете донора (extract скелета из клона, импорт FBX с биндом, cook SkeletalMesh).
3. **Фаза C — материалы**: свой набор MI_KAMAZ_* и перепайка слотов, вместо WorldGridMaterial.
